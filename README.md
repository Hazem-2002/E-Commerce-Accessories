# 🛒 E-Commerce Accessories Web App

A dynamic front-end E-Commerce web application built using **HTML5, CSS3, and JavaScript**.
The project simulates a real shopping experience with authentication, cart management, and persistent user data using LocalStorage.

## ✨ Features

* 🔐 User Authentication (Register / Login system)
* 💾 Persistent user data using **LocalStorage**
* 🔄 Dynamic switching between Login & Register modals
* 🛍️ Product listing with image, name, price, and category
* ➕ Add to Cart & Add to Favorites
* 🚫 Validation before actions (login required)

### 🛒 Cart System

* 🔔 Dynamic cart notification badge

* 🔄 Real-time updates

* ➕➖ Quantity control

* 👤 User-specific cart storage

* ⚡ Dynamic UI updates using JavaScript

* 🧠 State management using LocalStorage

* 🖥️ Designed primarily for desktop view

---

## 🛠️ Tech Stack

* 🌐 HTML5
* 🎨 CSS3
* ⚡ JavaScript (ES6)

## ⚙️ Installation

1. Clone the repository:

```bash
git clone https://github.com/Hazem-2002/E-Commerce-Accessories.git
```

2. Navigate to the project folder:

```bash
cd E-Commerce-Accessories
```

3. Open the project:

Open `index.html` in your browser
